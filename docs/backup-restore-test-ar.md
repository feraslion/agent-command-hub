# اختبار النسخ والاستعادة التجريبي

هذا المشروع لا ينفذ استعادة لقاعدة الإنتاج تلقائياً. بدلاً من ذلك، يختبر عقداً معزولاً يحمل وسم `test_only` ويثبت تساوي عدد المشاريع والمهام والأدلة بعد جولة النسخ والاستعادة في الذاكرة.

> لا تُعد هذه الجولة بديلاً عن تصدير بيانات المنصة أو استعادتها. لا تشغل أي حذف أو استعادة قاعدة بيانات فعلية إلا بعد الحصول على نسخة محدثة ومراجعة المالك وخطة رجوع مستقلة.

يشغّل الاختبار ضمن `pnpm test` ويغطي نجاح الجولة وكشف أي فقد في الأدلة. لا يقرأ بيانات الإنتاج ولا يكتبها.

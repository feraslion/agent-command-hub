# خيارات مؤجلة: Worker معزول وRedis وOpenTelemetry

هذه الخيارات مؤجلة عمداً لأن دورة Agent Command Hub الحالية مقيدة بمالك واحد وRunner محلي وحواجز موافقة واضحة. إضافتها قبل الحاجة قد تزيد نقاط الفشل وتوسع سطح الأسرار من دون فائدة تشغيلية متناسبة.

| الخيار | إشارة التفعيل | ما يضيفه | ما لا يضيفه |
| --- | --- | --- | --- |
| Worker معزول | مهام طويلة أو أكثر من عملية خادم واحدة | عزل عملية وهوية خدمة وعقود قابلة للاسترداد | صلاحية Docker أو Git أو ملفات جهاز المالك |
| Redis / Queue | ازدحام طابور أو حاجة retry مؤجل وموزع | حجز ذري وجدولة وتأخير وعدادات طابور | بديلاً عن الموافقات أو مصدر حقيقة للملفات |
| OpenTelemetry | تحقيقات تتطلب عبور API وWorker وRunner | Trace IDs ومقاييس وتأثيرات منظمة | تسجيل محتوى Workspace أو رموز الربط |

تسبق أي ترقية مراجعة تهديدات، وتنقيح للبيانات، وسياسة احتفاظ، واختبار استعادة. يبقى Runner المحلي مستقلاً: يستقبل طلباً معتمداً فقط ولا يلتقط مهاماً من أي طابور خارجي مباشرة.

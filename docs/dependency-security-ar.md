# فحص أمن التبعيات

يتضمن سير الجودة فحصين حاجبين قبل الدمج: فحص أسرار محلي للمصادر و**تدقيق تبعيات الإنتاج للمخاطر الحرجة**. اختير مستوى الحجب الحرج لأن سلسلة Expo الحالية ما زالت تعلن تحذيرات عالية انتقالية تتطلب ترقية SDK أو مكتبات رئيسية بعد اختبار توافق مخصص.

طبقت النسخة الحالية تجاوزات مقيدة لإصدارات مصححة من `shell-quote` و`tar` و`fast-uri` و`postcss`، ثم أعيد تدقيقها. لا يلغي هذا الحاجة إلى مراجعة التحذيرات العالية دورياً؛ إنه يمنع توقف خط الجودة على تحذيرات انتقالية لا يمكن ترقيتها بأمان داخل هذه الحزمة وحدها.

> لا تُدرج قيم اعتماد حقيقية في المصدر. فحص الأسرار يكتشف الأنماط الشائعة فقط، ولا يحل محل حفظ الأسرار في إعدادات البيئة أو تدقيق المراجعة البشرية.

# مراجع خيارات الاستضافة

تُستخدم هذه المراجع لتفسير الخيارات الظاهرة في شاشة **الخوادم والاستضافة**. لا تعني إضافتها أن التطبيق ينفذ نشراً خارجياً أو يحتفظ برموز وصول.

| المزوّد | الاستخدام داخل التطبيق | القيد الذي يجب مراجعته |
|---|---|---|
| Render | خادم API شخصي للتجربة | تتوقف خدمة الويب المجانية بعد 15 دقيقة من عدم النشاط وقد يحتاج الاستيقاظ إلى وقت؛ لا تُستخدم كعامل دائم أو قناة WebSocket مستمرة. |
| TiDB Cloud Starter | قاعدة بيانات MySQL/TiDB متوافقة مع المخطط الحالي | الحصة المجانية شهرية وقد تُقيّد الخدمة عند استنفادها. |
| Railway | بديل لتجربة API أو قاعدة بيانات | التجربة المجانية محدودة زمنياً ثم تختلف شروط الاستخدام. |
| Koyeb | بديل خادم API استعمالي | يعتمد على رصيد واستهلاك الخدمة بعد الحصة المتاحة. |

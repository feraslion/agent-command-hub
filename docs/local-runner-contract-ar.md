# عقد Runner المحلي المقيد

## الهدف

تتيح المرحلة الأولى تنفيذ ملف JavaScript مستقل ومحدود داخل حاوية Docker على جهاز المالك المرتبط، بعد موافقة صريحة من التطبيق. لا يملك Runner وصولاً إلى ملفات المشروع على الجهاز، ولا إلى الشبكة أو مفاتيح البيئة أو Docker socket داخل الحاوية.

## مسار التنفيذ

1. ينشئ المالك Runner من التطبيق ويحصل على مفتاح وتعليمة اتصال لمرة واحدة.
2. يشغل المالك العميل المحلي مع عنوان التطبيق والمفتاح والرمز.
3. يرسل العميل heartbeat ثم يحجز طلباً معتمداً فقط.
4. يتحقق الخادم والعميل من الملف والسياسة نفسها.
5. ينسخ العميل ملفاً واحداً إلى مجلد مؤقت ويشغله داخل حاوية مقيدة.
6. يعيد العميل حالة التنفيذ والرمز والمخرجات المقتطعة والمدة إلى السجل.

## حدود المرحلة الأولى

| المجال | مسموح | محجوب |
| --- | --- | --- |
| اللغة | JavaScript مستقل فقط (`.js`, `.mjs`, `.cjs`). | TypeScript، الحزم، وبناء المشاريع. |
| المسار | `source/` أو `tests/`. | المسارات المطلقة و`..` وبقية الأدلة. |
| الكود | دوال وحسابات محلية ومخرجات `console`. | الاستيراد و`require` والشبكة و`process.env` وملفات النظام و`eval`. |
| الحاوية | مستخدم غير جذري، جذر للقراءة فقط، مجلد مؤقت، شبكة معطلة. | Docker socket، قدرات Linux، عمليات غير محدودة، وربط مجلدات المستخدم. |
| الموارد | 15 ثانية، 256MB، 0.5 CPU، 64 عملية، ومخرجات مقتطعة. | التنفيذ المفتوح أو الموارد غير المحدودة. |

## الموافقات والتدقيق

كل طلب تنفيذ ينشئ موافقة بمستوى `APPROVAL`. لا يصبح الطلب قابلاً للحجز حتى يعتمد المالك القرار. عند الرفض يحظر الطلب. يسجل النظام هوية Runner والملف والحالة والمدة ورمز الخروج ومخرجات مقتطعة، ولا يسجل رمز Runner أو محتوى أسرار.

## تشغيل العميل على جهاز المالك

1. ثبت Docker Desktop أو Docker Engine وشغله، وتأكد أن المستخدم الحالي يملك صلاحية تشغيل `docker run`.
2. احصل على مفتاح Runner والرمز من إعدادات التطبيق، ثم شغل:

```bash
node runner/local-runner.mjs \
  --server https://YOUR-AGENT-HUB-DOMAIN \
  --runner RUNNER_KEY \
  --token RUNNER_TOKEN
```

3. لا تحفظ الرمز في Git أو في ملف مشترك. ألغ Runner من التطبيق فور فقد الجهاز أو الاشتباه في الرمز.

## التوسعة التالية

بعد إثبات هذه المرحلة باختبارات آمنة، يمكن إضافة صورة تعتمد على lockfile، ونسخة مؤقتة من Workspace كاملة، واختبارات محددة. لا يضاف Git أو النشر أو الشبكة أو الحزم إلا بقدرة منفصلة وموافقة مستقلة.

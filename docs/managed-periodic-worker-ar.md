# العامل المُدار الدوري غير الحساس

## القرار التشغيلي

يعتمد Agent Command Hub في هذه المرحلة **عاملاً مُداراً دورياً وغير حساس** داخل خدمة الخادم. يلتقط العامل أوامر التخطيط الجافة، يستعيد العقود المنتهية، يحدث نبض المراقبة، ويحوّل الأمر إلى خطة وسجل أحداث قابلين للمراجعة. لا يمثل العامل Runner محلياً ولا يحل محله.

| المجال | متاح للعامل | ممنوع صراحةً |
| --- | --- | --- |
| الأوامر | حجز أمر جاف، إنشاء خطة، متابعة محرك مهام جاف | تنفيذ شيفرة أو shell |
| البيانات | قراءة الحد الأدنى للأمر وخطة التنفيذ وتسجيل الحالة | ملفات الجهاز وWorkspace والأسرار |
| البنية | نبضة داخل الخادم واسترداد عقد منتهي | Docker وGit والشبكة الخارجة |
| التغيير | خطط ومهام قابلة للمراجعة | PR أو نشر أو حذف أو دمج |

> كل تنفيذ شيفرة، تعديل Workspace، Pull Request، نشر أو حذف يبقى خلف طلب موافقة مستقل. لا يوجد مسار في العامل لتحويل الموافقة إلى فعل ذي امتيازات.

## دورة العمل والقدرة على الاسترداد

تعمل الحلقة كل 10 ثوانٍ افتراضياً، ولا تسمح بتشغيل متوازٍ داخل العملية نفسها. تستعيد العقود بعد 45 ثانية، ثم تضع الأمر في الطابور أو تسجله فاشلاً وفق حد المحاولات المحدد. يتيح `DRY_WORKER_ENABLED=false` تعطيل الحلقة بصورة صريحة؛ وتعرض لوحة الصحة وقت آخر نبضة، عدد العقود المحجوزة، والخطط المنشأة.

العامل مناسب لتخطيط الأوامر وتنسيق دورة الوكلاء الجافة والتلخيصات المشتقة. إذا احتاج المنتج لاحقاً تنفيذ مهام كثيفة أو موثوقية عالية بين عدة عمليات، يجب نقل الحجز إلى عامل معزول مع طابور متين، لا توسيع صلاحيات العامل الحالي.

## مسار ترقية مؤجل

| الحاجة المستقبلية | المسار الآمن | الشرط السابق |
| --- | --- | --- |
| توسع أفقي أو تنفيذ طويل | Worker معزول بهوية خدمة محدودة | Queue متين وعقود idempotent |
| طوابير متعددة واكتشاف تأخر | Redis أو خدمة طوابير مدارة | مفاتيح تشغيل وقياسات انتظار |
| تتبع من طلب إلى Worker وRunner | OpenTelemetry | معرف تتبع موحد وتنقيح بيانات traces |

لا تضيف هذه الوثيقة تلك الخدمات ولا تمنح العامل الحالي أي صلاحيات جديدة؛ إنها توثق معايير اتخاذ القرار فقط.

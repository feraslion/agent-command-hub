# سياسة بوابة النماذج ودورة الوكلاء

**تاريخ تدقيق الكتالوج:** 20 أغسطس 2026.  
**مصدر الكتالوج:** بوابة النماذج الخادمية المدمجة `BUILT_IN_FORGE_API_URL/v1/models`، قراءة وقت التدقيق فقط.

## النماذج المتاحة وقت التدقيق

| النماذج المرصودة | الاستخدام في السياسة |
| --- | --- |
| `gpt-5-nano`، `gpt-5-mini`، `gpt-5`، `gpt-5.5` | مخرجات منظمة خفيفة أو استدلال أقوى عند الحاجة. |
| `claude-haiku-4-5`، `claude-sonnet-4-6`، `claude-opus-4-6`، `claude-opus-4-7` | تحليل وفرق شفرة ومراجعة موسعة ضمن سياسة الدور. |
| `gemini-3-flash-preview`، `gemini-3.1-pro-preview` | بدائل سياق واسع؛ لا تعتمد السياسة عليها كخيار أول ثابت. |

لا تسجل نقطة نهاية الكتالوج في هذه الجلسة أسعاراً قابلة للاستهلاك؛ لذلك لا تدّعي البوابة احتساب تكلفة فعلية من عدد الرموز. بدلاً من ذلك، تُحجز **سقوف تكلفة صريحة** قبل الإرسال وتُسوى كحجز منفذ أو محرر، إلى أن تتاح تسعيرة خادمية قابلة للتدقيق.

## اختيار النموذج بحسب الدور

| الدور | ترتيب الاختيار إذا كان النموذج متاحاً | سقف الحجز الافتراضي | الصلاحية |
| --- | --- | ---: | --- |
| Planner | `gpt-5-mini` ← `gpt-5` | 0.05 USD | خطة وأسئلة ومعايير قبول JSON فقط. |
| Coder | `claude-sonnet-4-6` ← `gpt-5` | 0.15 USD | اقتراح فرق فقط؛ لا كتابة Workspace ولا تشغيل ولا Git. |
| QA | `gpt-5-mini` ← `claude-haiku-4-5` | 0.05 USD | PASS/FAIL وأدلة وفجوات JSON فقط. |
| Reviewer | `gpt-5` ← `claude-sonnet-4-6` | 0.10 USD | تقييم نطاق ومخاطر وقرار مراجعة فقط. |
| Debugger | `gpt-5` ← `claude-sonnet-4-6` | 0.10 USD | تشخيص وأصغر إصلاح مقترح؛ محاولتان كحد أقصى لكل مهمة. |

## حواجز غير قابلة للتجاوز

| الحاجز | التطبيق |
| --- | --- |
| الخادم فقط | لا تصل بيانات اعتماد النموذج أو نقطة النهاية إلى تطبيق الجوال. |
| سياق محدود | لا يُقبل تشغيل دور من دون `ContextPackage` يملكه المشروع؛ المراجع منقحة ولا تتضمن محتوى Workspace الخام. |
| عقد JSON | تمر مخرجات كل دور عبر Zod بعد استخدام JSON Schema صارم في الاستدعاء. |
| حجز مالي | يمنع الإرسال إذا تجاوز المنصرف مع الحجوزات النشطة سقف المشروع. |
| لا تنفيذ خفي | Coder وDebugger ينتجان فرقاً أو إصلاحاً مقترحاً فقط. التطبيق الفعلي يبقى عبر مسار Workspace والمراجعات والموافقات الموجود. |
| فصل المراجعة | Reviewer لا يطبق فرق Coder، وQA لا يغير حالة المهمة تلقائياً. |
| إعادة محاولة محدودة | Debugger يرفض محاولة ثالثة للمهمة نفسها قبل تدخل المالك. |

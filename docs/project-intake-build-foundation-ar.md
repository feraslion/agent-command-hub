# أساس استيراد المشاريع وطلبات البناء المحكومة

## الغرض

تضيف هذه الطبقة مساراً مملوكاً لصاحب المشروع لاستقبال **مرجع مشروع** أو **أرشيف ZIP** ثم إنشاء طلب بناء قابل للمراجعة. وهي لا تعد بيئة تنفيذ أو منصة توزيع. لا تفك الأرشيف، ولا تستنسخ Git، ولا تتصل بواجهة مزود مستودعات، ولا تشغل Docker، ولا ترفع نتائج بناء.

> **القاعدة:** المصدر أولاً، ثم قرار بناء صريح، ثم إثبات Runner محلي، ثم موافقة منفصلة قبل أي تنفيذ فعلي.

| المدخل | التحقق المنفذ | الناتج المخزن | ما يبقى محجوباً |
| --- | --- | --- | --- |
| ZIP حتى 8MB | امتداد `.zip`، تطابق الحجم، وترويسة ZIP | كائن تخزين وArtifact وسجل Import وصفي | فك الضغط، قراءة محتوى المصدر، التشغيل، البناء |
| رابط مستودع | HTTPS فقط، بلا بيانات اعتماد أو منفذ أو query، ومضيف GitHub/GitLab/Bitbucket عام | مرجع مستودع وImport وصفي | clone، fetch، OAuth، token، push، merge |
| طلب بناء | هدف محدد ووصف ونطاق، ومصدر من المشروع نفسه | Build Request وحالة `awaiting_approval` وطلب موافقة | أي أمر build أو Docker أو نشر أو إنتاج APK |

## نموذج البيانات

تسجل `project_imports` المصدر وملخصه المنقح، بينما تسجل `project_build_requests` هدف البناء وحالته وقرار الموافقة المرتبط. يبقى الملف الكبير خارج قاعدة البيانات في التخزين، ويخزن `artifacts` مرجع الكائن فقط. يربط ذلك رحلة الاستيراد بسجل أحداث المشروع وبنفس حراسة ملكية المشروع المستخدمة في بقية المنصة.

## مسار الواجهة

تظهر بطاقة **«استيراد وبناء محكوم»** في كل مشروع. تتيح اختيار ZIP من الهاتف أو تسجيل رابط مستودع، ثم تعرض المصادر المحفوظة وطلبات البناء. لا يظهر زر تنفيذ؛ ينتهي الإجراء بإنشاء طلب موافقة. يظل مصدر المشروع قابلًا للمراجعة قبل أن يسمح الإصدار اللاحق بتمريره إلى Runner المثبت.

## شروط تفعيل البناء الفعلي لاحقاً

لا يُضاف تنفيذ البناء إلا بعد تحقق الشروط التالية مجتمعة:

1. Runner محلي مقترن ومثبت بنبضة وطلب تنفيذ معتمد على جهاز المالك.
2. سياسة لغة/حزمة محددة، مثل Node أو Android، مع صورة Docker مثبتة وlockfile.
3. مصدر مشروع معتمد، وسقف حجم وملخص فحص وصفي، وطلب بناء معتمد لكل تشغيل.
4. سجل أدلة لرمز الخروج والمدة والمخرجات المنقحة، من دون رفع أو دمج تلقائي.

تظل منصة المستودعات في هذه المرحلة **مرجعاً فقط**. يقتضي أي اتصال OAuth أو webhook أو API لمزود خارجي موافقة منفصلة وتخزين الاعتماد عبر الإعدادات الآمنة، لا في التطبيق أو Git أو المحادثة.

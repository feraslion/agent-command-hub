# تكامل دليل Public APIs

## المصدر المعتمد

- الواجهة العامة: `https://publicapis-vmuetrsw.manus.space/api/v1/apis/search`
- وثيقة البوابة: `https://publicapis-vmuetrsw.manus.space/?category=Cryptocurrency&auth=No`
- المصادقة: لا تتطلب مفتاح API وفق صفحة البوابة.

## العقد المستخدم

يستقبل مسار البحث `query` و`category` و`auth` و`https` و`cors` وقيود الترقيم. تعيد الاستجابة JSON يتضمن `data` للنتائج و`meta` لبيانات الترقيم. تعرض الخدمة ترويسات حد الطلب، وتعيد `429` مع `Retry-After` عند تجاوزه.

## سياسة Agent Command Hub

لا يستدعي التطبيق هذه الواجهة من الجوال مباشرة. يمر البحث عبر خادم التطبيق، ويقتصر على HTTPS والمضيف العام الثابت ونقطة النهاية المعتمدة ومدخلات محددة. تُسجل صيغة الاستعلام وعدد النتائج والوقت في حملة البحث، ولا تُسجل مفاتيح أو مخرجات غير منقحة. يبقى الخيار الذاتي معطلاً افتراضياً ولا ينفذ بحثاً في الخلفية أو بشكل متكرر حتى يختار المالك نموذج التفعيل صراحة.

## البحث الذاتي المعتمد

عند تفعيل المالك لخيار البحث الذاتي، ينشئ الخادم بصمة تشغيل HMAC مشتقة من سر الخادم وحملة البحث، ولا تنقل هذه البصمة أو السر إلى العميل. يمكن للوكيل تنفيذ استعلام واحد فقط للدليل في كل حملة، تلقائياً عند إنشاء حملة جديدة أو يدوياً للحملة الحالية. يتحول كل مرشح إلى دليل من نوع `web` ودرجة ثقة `untrusted`، ولا يبدأ أي تنفيذ أو دمج أو بناء من النتيجة.

| الحالة | الأثر |
| --- | --- |
| معطل | لا يجري الخادم أي طلب إلى الدليل. |
| مفعّل | يسمح باستعلام واحد مسجل لكل حملة تخطيط. |
| حد الطلب أو خطأ الشبكة | لا يعاد الطلب تلقائياً، ويظهر الخطأ للمالك. |

تقتصر النتيجة المخزنة على اسم الواجهة ووصفها وفئة الدليل ونوع المصادقة وحالة HTTPS ورابط التوثيق. تبقى الأوصاف بيانات غير موثوقة، ولا تعامل كتعليمات للوكلاء.

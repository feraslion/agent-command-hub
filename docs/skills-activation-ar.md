# تفعيل مهارات Agent Command Hub

## ما فُعّل داخل المشروع

| المجال | التطبيق الحالي | الحاجز المتبقي |
| --- | --- | --- |
| تشغيل LLM منظم | أدوار Planner وCoder وQA وReviewer وDebugger تعمل من الخادم بمخرجات JSON، اختيار نموذج حي، وحجز تكلفة. | تشغيل تجربة مملوكة بعد تسجيل الدخول وفتح مشروع. |
| ملفات Artifact | يحفظ كل مخرج نموذج مكتمل كملف JSON منقح في التخزين، ويعرضه ضمن سجل الأدلة. | مراجعة ملف الدليل من مشروع حي. |
| تنبيه المالك | يرسل اكتمال أو فشل دور الوكيل كتنبيه منقح لا يؤثر في نتيجة التشغيل. | التحقق من وصول تنبيه فعلي بحساب المالك. |
| ملخص التشغيل | زر داخل Runtime ينشئ ويرسل ملخصاً قرائياً من صحة النظام. | لا توجد جدولة تلقائية بعد. |
| Public APIs | بحث ذاتي محكوم واستعلام واحد لكل حملة عند التفعيل. | تجربة حملة مملوكة بعد تسجيل الدخول. |

## مسارات لا تزال معطلة افتراضياً

| المسار | لماذا لا يفعّل الآن | ما يلزم للتفعيل |
| --- | --- | --- |
| مهام Manus خارجية | لا يوجد اعتماد API أو سياسة تأكيد للمهمة الخارجية. | اعتماد خادم-فقط، مخرج JSON، وسياسة انتظار الموافقة. |
| الموصلات الخارجية | لا يوجد موصل مفعّل في الجلسة. | اختيار خدمة محددة، توثيق رسمي، واعتماد من المالك. |
| الملخص المجدول | لا يبدأ المشروع مؤقتات داخل الخادم. | نشر النسخة، معالج `/api/scheduled/`، وجدولة منخفضة التردد معرّفة للمالك. |
| Runner دائم | يتطلب Docker وأدوات نظام غير متاحة من الهاتف. | جهاز Docker، إثبات نبضة، Smoke Test، وتنفيذ معتمد موثق. |

## خيارات التشغيل التلقائي لاحقاً

| الخيار | النتيجة | التكلفة والإعداد |
| --- | --- | --- |
| ملخص يدوي عند الطلب | يرسل المالك ملخص Runtime من التطبيق. | جاهز الآن ولا يحتاج خدمة دائمة. |
| ملخص دوري منخفض التردد | يرسل الخادم ملخصاً في وقت محدد عبر مسار مجدول موثق. | يحتاج نشر النسخة واعتماد تكرار صريح. |
| عامل دائم محلي | ينفذ Runner المقيد على جهاز Docker الشخصي. | يحتاج بقاء الجهاز متصلاً، لكنه يحافظ على الملفات محلياً. |
| مهام تحليل خارجية | تنشئ مهمة مستقلة بمخرجات JSON قابلة للتدقيق. | تحتاج اعتماد API خادم-فقط وسياسة موافقة مستقلة. |

> لا يرسل أي مسار معطل أسراراً أو كود Workspace أو ينفذ بناءً أو دمجاً. التفعيل اللاحق منفصل لكل مسار ويستلزم موافقة المالك.
